# 🩺 Breast Cancer Classification Using Logistic Regression

## 📌 Project Overview

This project implements the **Logistic Regression** algorithm to classify breast cancer tumors as **Benign** or **Malignant** based on diagnostic features. Using the Breast Cancer dataset, the model is trained and evaluated with Python and Scikit-learn to demonstrate binary classification in healthcare applications.

---

## 🎯 Objectives

- Predict breast cancer diagnosis using Logistic Regression.
- Train and evaluate a binary classification model.
- Measure performance using classification metrics.
- Understand the application of machine learning in healthcare.

---

## 📂 Dataset

**Dataset:** Breast Cancer Dataset

### Features
The dataset contains multiple diagnostic features extracted from breast cancer cell images.

### Target Variable
- **Class**
  - Benign (2)
  - Malignant (4)

The Logistic Regression model successfully classified breast cancer tumors with an accuracy of approximately **95.6%**.
